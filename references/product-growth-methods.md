# 产品与增长方法

用于产品分析、增长循环、竞品分析、功能拆解、市场框架和产品策略。

## 产品分析顺序

1. 识别用户和 job-to-be-done。
2. 找到产品创造价值的关键时刻。
3. 画出从获客到价值实现的漏斗。
4. 选择最能代表当前瓶颈的指标。
5. 按用户类型、渠道、生命周期阶段和意图分层。
6. 把指标变化连接到产品机制，而不是只看 UI 或活动表层变化。

## OSM：Objective、Strategy、Measure

当目标、动作和指标脱节时，使用 OSM：

1. Objective：用户或业务结果。
2. Strategy：创造结果的路径和关键动作。
3. Measure：判断策略是否有效的指标和目标。

不要从一堆可用指标开始做增长分析。先从决策和瓶颈开始，再选择指标。

## 增长视角

- AARRR：acquisition、activation、retention、referral、revenue。
- Growth loop：input、action、output、reinvestment。
- Activation：首次有意义价值时刻，不只是注册。
- Retention：重复获得价值，不只是重复访问。
- Monetization：支付意愿和支付成功，不只是 checkout 曝光。
- 阶段指标：按激活、参与、留存、变现、扩张或效率匹配指标；主指标必须配护栏指标。

## 竞品分析

竞品分析是为了澄清选择，不是为了抄功能。

先定义：

- 决策问题：定位、路线图、定价、入场、增长机会或风险监控。
- 比较对象：用户需求、job-to-be-done、场景、商业模式或替代行为。
- 比较维度：先定维度，再收集证据。

检查：

- 目标用户
- 核心承诺
- 获客渠道
- 定价模型
- 激活路径
- 留存机制
- 变现路径
- 功能深度
- 信任和风险处理
- 竞品选择不竞争的地方

竞品跟踪：

- 把已发布事实和推断意图区分开。
- 看到连续版本模式后，再推断方向。
- 把发现转成观察项、响应方案或验证问题。

框架提示：

- SWOT：strengths、weaknesses、opportunities、threats。
- PEST：political、economic、social、technological context。
- Five forces：supplier、buyer、substitutes、entrants、rivalry。
- Competitive canvas：比较用户、场景、价值、功能、指标和 moat。
- APPEALS：扫描 access、packaging、performance、usability、assurance、price/value；按品类调整维度。

```text
成功状态：
影响指标：
失败模式：
权衡：
```

## 常见错误

- 只描述功能，不描述用户场景。
- 用获客指标判断留存问题。
- 抄竞品 UI，而不理解底层模型。
- 把框架当答案。
- 忽视变现或运营成本。
